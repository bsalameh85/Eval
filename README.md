# نظام تقييم أداء الموظفين (نسخة ثابتة)

موقع ثابت (HTML + CSS + JS) بلا خادم ولا قاعدة بيانات ولا تسجيل دخول، يعمل مباشرة على **GitHub Pages**.
لا يتم حفظ أي بيانات: اختر النموذج، عبّئ البيانات، ثم اطبع أو احفظ PDF.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد في جذر المستودع.
2. من المستودع: **Settings ← Pages**.
3. في **Build and deployment** اختر Source = **Deploy from a branch**، ثم Branch = **main** والمجلد **/ (root)**، واضغط Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`

## الطباعة
في نافذة الطباعة: الهوامش «بلا»، وفعّل «رسومات الخلفية». الصفحات 4 و5 و7 تُطبع عرضياً تلقائياً.

## هيكل الملفات
- `index.html`: اختيار النموذج. `evaluate.html?type=...`: صفحة التقييم.
- `assets/data.js`: النماذج والأوزان والكفايات وبنك المسميات الوظيفية وبنك الإجراءات التطويرية.
- `assets/bank.js`: توليد التقييم التلقائي وخطة التطوير (كان `api.php`).
- `assets/evaluate.js`: واجهة النموذج والحساب وتوزيع العلامة.
